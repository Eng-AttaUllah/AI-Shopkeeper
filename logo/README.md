# Logo work

Two passes live here.

## Current — EasyShop Book-E

`easyshop/` is the active direction: the Open Ledger mark rebuilt as an **E**, with an
**EasyShop** wordmark. Three variants (B1, B2, B3) are ready to compare.

**Open `easyshop/preview.html`.**

- `easyshop/concepts/` — mark + squircle tile for each variant
- `easyshop/lockups/` — mark + wordmark lockups
- `easyshop/png/` — 512px and 1024px previews
- `easyshop/README.md` — construction and wordmark details

The winner then becomes the favicon, app icons, header brand, and sign-in card.

## First pass — six directions (archive)

`concepts/` holds the original exploration for “AI Shopkeeper”: six marks, each as a
standalone mark and an app tile. It is kept for reference; `preview.html` compares them.

| #   | Concept          | Idea                                                                        | Metaphor             |

## Rules kept in both passes

- 48-unit grid, flat fills, no gradients, glows, or shadows.
- No text inside a mark, so the same artwork survives the Pashto / RTL interface.
- PNGs are previews; the SVGs are the source of truth.
